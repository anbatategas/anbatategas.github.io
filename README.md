# Anastasios N. Batategas - Personal Website

https://anbatategas.com

Welcome to the source code repository for my personal academic portfolio and webpage. 

This website serves as a living archive of my academic trajectory as an undergraduate student in the School of Applied Mathematical & Physical Sciences (SEMFE) at NTUA. It hosts a curated collection of my theoretical and computational physics projects, laboratory reports, university notes, and my formal Curriculum Vitae.

## Built With

This site is statically generated and built for performance, utilizing a custom-tailored responsive design without relying on heavy frontend frameworks.

- **[Hugo](https://gohugo.io/)** - The world's fastest framework for building websites.
- **Custom HTML5 & CSS3** - Fully bespoke CSS architecture utilizing CSS Grid and Flexbox for seamless cross-device scaling.
- **Vanilla JavaScript** - Lightweight DOM manipulation for theme toggling, search, and UI state management.
- **KaTeX** - For fast, lightweight client-side rendering of complex mathematical and physics notation.
- **GitHub Actions & Cloudflare** - For automated CI/CD deployment and DNS management.

### The Development Process
This site was originally based on the Hugo theme *Scholar-lite*. However, rather than using it out of the box, I extracted the core files and completely overhauled the architecture—treating the original code like a block of marble to carve my own design out of. 

By reverse-engineering the templating logic and writing extensive custom layout overrides, this project served as my first hands-on exposure to HTML and CSS. The result is a highly customized, lean portfolio that was as informative to build as it is functional.

## Responsive Design

The layout is specifically engineered to be completely responsive. It utilizes CSS media queries and relative scaling to ensure that dense academic information (such as mathematical formulas, data tables, and high-resolution computational phase-space plots) remains highly readable on any screen size, from wide desktop monitors to mobile devices.
